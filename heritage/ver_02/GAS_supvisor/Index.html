1. 지리기반 AI RAG 문화유산 매칭 파이프라인

Query Input 사용자 자연어 질문
[Query Input]
사용자가 검색창에 입력한 자유 키워드와 지역명(예: '세종시 조용한 사찰')을 백엔드에 쿼리로 전달합니다.
➔
공공 OpenAPI 검색 국가유산 지정 조회
[국가유산 공간정보 WFS API]
국가유산청의 `openapi/xmlService/spca.do` (WFS) 서비스를 연동하여 지정 문화유산 실시간 데이터를 조회하고 최적의 유산 5선을 매칭합니다.
➔
LLM Node (Gemini) 추천 맥락 및 이유 추론
[LLM Reasoning Brain]
조회된 유산의 메타데이터 정보를 조합하고, 질문의 의도에 어울리는 추천 근거 텍스트를 추론을 거쳐 생성합니다.
➔
Map Mapping Output 유산 5선 카드 & 맵 마킹
[Output Interface]
종합된 5선 목록을 인터페이스로 전달하여 지도 위에 시각적인 핀 마킹 및 선형 경로를 동적으로 표시합니다.

2. AI 가이드북 멀티에이전트 스토리북 생성 파이프라인 (LangChain StateGraph)

입력 파라미터 수신 여행 명소 10선 & 교통수단
사용자가 작성 완료한 10대 추천 여행 코스 목적지 목록과 이동 방식(도보/대중교통/차량) 파라미터를 에이전트 그래프에 입력합니다.
➔
공공포털 API 지식 증강 국가유산 OpenAPI & KTO TourAPI
선택된 유산들의 공식 기록 정보와 관광공사 Open API 연계 주변 관광 명소 상세안내 사항을 실시간으로 수집하여 RAG 지식 풀을 보강합니다.
🔄 LangChain StateGraph 협업 에이전트 핵심 루프
(1) 기획/동선 에이전트 10km 인근시설 수집 및 가까운 거리 최적화
WFS 및 한국관광공사 API를 연계하여 10km 이내의 음식점, 카페, 주차장, 공공 화장실 데이터를 거리순 수집한 뒤, 가까운 거리 기반(TSP 최적화)으로 이동 동선을 정밀 설계합니다.
(2) 스토리텔링 에이전트 감성 동화책(Fairytale Book) 본문 창작
수집된 재미있는 설화와 역사적 비화를 엮어 '옛날 옛적에~', '~했답니다'의 친근하고 따뜻한 구연동화 형식의 완성도 높은 동화책 형태 본문을 창작합니다.
(3) 글로벌 번역 에이전트 영문 동화 가이드북 번역 및 고도화
해외 관광객과 외국인 어린이들도 생생하게 감상할 수 있도록 감성적인 동화 작법 톤을 유지하여 자연스러운 영문 동화 스토리로 번역합니다.
(4) 감수/피드백 에이전트 지리 좌표 및 역사적 고증 최종 검수
출판 전 전체 텍스트와 좌표가 올바르게 기재되었는지 정합성을 크로스체크하여 오작동과 오류를 사전에 차단합니다.
최종 아티팩트 결과 도출 동화책 카드 스토리보드 생성 & 한국어/영어 번역본 배포 및 오디오 TTS 합성
완성된 오디오 스크립트를 SpeechSynthesis API와 연동해 성우 보이스의 생생한 사운드로 즉시 낭독을 시작합니다.

3. AI 에이전트 벡터 캐싱 및 시맨틱 라우터 파이프라인 (Vector Semantic Caching & Routing)

쿼리 의도 분석 (Router) OpenAI Semantic Router
입력된 자연어 쿼리의 의도를 LLM 기반 시맨틱 라우터가 분석하여 역사/지식을 묻는 'heritage' 또는 코스 생성을 묻는 'course' 경로로 자동 분기시킵니다.
➔
유사도 매칭 (Router Hit) pgvector match_courses RPC
'course' 쿼리 시, DB(courses_vector)에 축적된 코스 임베딩 벡터들과 코사인 유사도를 연산하여 적합한 기 생성 코스가 발견되면 200ms 만에 즉시 반환(Router Hit)합니다.
➔
3개 에이전트 구동 (Router Miss) 10km 연계 ➔ 거리순 정렬 ➔ 번역
캐시 미적중 시, 10km 이내의 연계 식당/주차장/화장실 정보를 바탕으로 최단거리 최적 동선(TSP)을 설계하고 흥미진진한 동화 원고를 신규 창작합니다.
➔
신규 벡터화 캐싱 (Cache Write) OpenAI Embedding & DB Caching
새로 도출된 문화유산 가이드북 본문과 코스 데이터를 1536차원 벡터로 인코딩하여 Supabase pgvector(courses_vector) 테이블에 삽입(벡터화 진행)하여 다음 검색 시 초고속 재사용하도록 캐싱합니다.
