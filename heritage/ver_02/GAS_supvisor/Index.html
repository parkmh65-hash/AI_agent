1. 지리기반 AI RAG 문화유산 & 주변 관광지 연계 탐방 코스 라우팅 파이프라인

Query Input 자연어 질문 입력
[자연어 쿼리 수신]

➔
유산 후보 풀 통합 OpenAPI 15선 + DB 15선
[Heritage Candidate Merge]
국가유산 OpenAPI 조회 후보와 DB에 이미 등록되어 있던 유산을 중복 제거하여 풍부한 후보 풀을 구성합니다.
➔

[select_top_heritages_via_llm]
통합 후보들 중 사용자의 질문 의도 및 테마에 완벽히 부합하는 최적의 문화유산 5선을 LLM 분석으로 선별합니다.
➔
좌표 검증 & 저장 Geocoding 보정 Upsert
[Coordinate & DB Upsert]

관광지 후보 통합 KTO API 15선 + DB 15선

LLM 관광지 5선 선별 근접 연계 AI 매칭

2. AI 가이드북 멀티에이전트 스토리북 생성 파이프라인 (LangChain StateGraph)

입력 파라미터 수신 최단경로 10선 코스 & 교통수단
사용자가 코스 생성을 마친 10대 추천 탐방 장소 목록과 차량/대중교통 이동 수단을 에이전트 그래프 입력으로 세팅합니다.
➔
RAG 공식 정보 조회 공간정보 API & KTO & 위키백과
선택 장소들의 공식 텍스트, 인근 관광시설 정보, 위키백과/네이버 지식 백과 등의 전설·역사 Fun Fact 등을 수집해 지식 풀을 보강합니다.
🔄 LangChain StateGraph 협업 에이전트 핵심 루프
(1) 교육 및 재미 분석 에이전트 (Analyzer) 각 장소의 '교육적 가치'와 '재미 요소' 입체 재분석
수집된 RAG 지식을 바탕으로 각 장소의 역사적 배울 점(교육적 의미)과 전설 및 흥미진진한 탐방 포인트(재미적 요소)를 전문적으로 분석 및 구조화합니다.
(2) 엄마 목소리 작가 에이전트 (Storywriter) 엄마 말투의 자녀 전달용 1page 동화 원고 집필
분석된 교육/재미적 가치를 부드럽게 융합하고, 엄마가 아이에게 다정하고 이해하기 쉽게 대화식(~단다, ~했단다)으로 전달하는 약 1000자 분량의 감성 가이드글로 재창작합니다.
(3) 글로벌 번역 에이전트 (Translator) 따뜻한 엄마 감성 영문 번역
다정한 엄마의 스토리 감성과 어휘 느낌을 그대로 살려 외국인 어린이와 다문화 가정도 읽을 수 있는 자연스러운 영어 가이드북 스토리로 번역합니다.
(4) 엄마 말투 검수 에이전트 (Critic) 구어체 톤 및 최종 구조화 검증
스토리보드 카드의 가이드 팁과 낭독 스크립트 전반에 다정한 엄마의 대화식 음성이 이질감 없이 완벽히 유지되는지 최종 오디팅 및 구조 정비를 완료합니다.
최종 아티팩트 결과 도출 엄마 목소리 한국어/영어 번역 가이드 아티클 배포 및 스토리보드 카드 렌더링
정제된 최종 엄마의 낭독용 스크립트는 성우의 따뜻한 오디오 합성(SpeechSynthesis) 출력과 연계되어 사용자 화면으로 즉시 흘러나옵니다.

3. AI 에이전트 벡터 캐싱 및 시맨틱 라우터 파이프라인 (Vector Semantic Caching & Routing)

쿼리 의도 분석 (Router) OpenAI Semantic Router
입력된 자연어 쿼리의 의도를 LLM 기반 시맨틱 라우터가 분석하여 역사/지식을 묻는 'heritage' 또는 코스 생성을 묻는 'course' 경로로 자동 분기시킵니다.
➔
유사도 매칭 (Router Hit) pgvector match_courses RPC
'course' 쿼리 시, DB(courses_vector)에 축적된 코스 임베딩 벡터들과 코사인 유사도를 연산하여 적합한 기 생성 코스가 발견되면 200ms 만에 즉시 반환(Router Hit)합니다.
➔
3개 에이전트 구동 (Router Miss) 10km 연계 ➔ 거리순 정렬 ➔ 번역
캐시 미적중 시, 10km 이내의 연계 식당/주차장/화장실 정보를 바탕으로 최단거리 최적 동선(TSP)을 설계하고 흥미진진한 동화 원고를 신규 창작합니다.
➔
신규 벡터화 캐싱 (Cache Write) OpenAI Embedding & DB Caching
새로 도출된 문화유산 가이드북 본문과 코스 데이터를 1536차원 벡터로 인코딩하여 Supabase pgvector(courses_vector) 테이블에 삽입(벡터화 진행)하여 다음 검색 시 초고속 재사용하도록 캐싱합니다.
